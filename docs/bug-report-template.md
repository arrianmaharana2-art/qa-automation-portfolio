# Bug Report Template

Copy this template for each defect found. Attach the screenshot from `target/screenshots/` when a test fails.

| Field | Details |
|-------|---------|
| Bug ID | BUG_001 |
| Title | Short summary of the problem |
| Application / module | For example: SauceDemo / Checkout |
| Environment | Browser and version, operating system, URL |
| Severity | Critical / Major / Minor / Trivial |
| Priority | High / Medium / Low |
| Related test case | For example: TC_CHK_02 |
| Status | New / Open / Fixed / Retest / Closed |
| Reported by | Your name |
| Date | DD-MM-YYYY |

## Steps to reproduce

1. Step one
2. Step two
3. Step three

## Expected result

What should happen.

## Actual result

What actually happened.

## Attachments

Screenshot, video or API response.
